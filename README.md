# Python To-Do List

A simple command-line To-Do List application written in Python.

## Features

- View tasks
- Add tasks
- Remove tasks
- Easy-to-use menu system

## How to Run

1. Make sure Python is installed.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run:

```bash
python todo.py
```
